# Task 2 – Exploratory Data Analysis (EDA)
**WeIntern Pvt Ltd | Data Science Week 2 Internship**

## Project Overview
This repository contains a comprehensive **Exploratory Data Analysis** performed on the cleaned Superstore Sales dataset.

The goal was to uncover patterns, trends, correlations, and actionable business insights through multiple visualization techniques.

---

## Files Included

| File | Description |
|------|-------------|
| `Task2_Exploratory_Data_Analysis.ipynb` | Full EDA notebook with visualizations & insights |
| `cleaned_superstore_sales.csv` | Cleaned dataset used for analysis |

---

## Analysis Performed

- Descriptive Statistics
- Histograms + KDE plots
- Correlation Heatmap
- Box plots (by Category & Region)
- Time-series trend (Monthly Sales & Profit)
- Group-by analysis (Category × Region, Customer Segment)
- Scatter plots (Discount vs Profit, Unit Price vs Sales)
- 3+ Actionable Business Insights + Recommendations

---

## Key Insights

1. **Technology** category drives the highest average sales, while **Furniture** shows higher profit variance.
2. Higher **discounts** are strongly associated with lower (often negative) profits.
3. **West** and **Ontario** regions dominate both sales volume and profitability.
4. Clear seasonality and upward growth trend observed from 2009–2012.
